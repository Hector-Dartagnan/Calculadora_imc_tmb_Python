# TMB_NoGui_Python
<h3>Sobre o que se trata?</h3>
<p>Minha ideia inicialmente é fazer um Projeto simples em Python (aplicação de console) que calcula o Índice de Massa Corporal (IMC) e Taxa Metabólica Basal (TMB).<br>
Foi criado com o intuito de treinar e reforçar conceitos fundamentais da linguagem, como funções, parâmetros, retorno de valores, estruturas condicionais e organização de código, sem o uso de interface gráfica.</p>

<h3>Mudanças futuras</h3>
<p>Em breve pretendo repetir o mesmo projeto, porém com interface gráfica e persistência de dados</p>
